# Legal Launch Checklist

실제 결제 오픈 전 법적/소비자 고지 리스크를 줄이기 위한 운영 체크리스트다. 법률 자문 대체가 아니며, 최종 약관과 개인정보처리방침 문구는 오픈 전 별도 검토한다.

## Launch Blockers

- [x] 현재 간이과세자 통신판매업 신고 면제 상태와 표시 문구를 확정한다. 과세 유형 또는 전년도 거래 규모가 바뀌면 매년 다시 확인한다.
- [x] 고객센터 전화번호, 이메일, 운영 시간을 실제 값으로 확정한다.
- [x] 호스팅 제공자를 Amazon Web Services로 확정한다.
- [ ] 계좌입금 현금 결제 기준 구매안전서비스를 은행 에스크로 또는 소비자피해보상보험으로 확보한다. 특히 1회 5만원 이상 비신용카드 선불 주문에 적용 가능한 수단이어야 한다.
- [ ] 구매안전서비스 계약과 고객 선택 화면이 준비되기 전에는 실제 판매 주문을 받지 않는다.
- [x] 구매안전서비스 준비 전 운영 주문을 서버와 고객 화면에서 함께 차단한다. `APP_SALES_ENABLED`의 운영 기본값은 `false`다.
- [ ] 통신판매업 신고에 필요한 구매안전서비스 이용확인증 또는 대체 증빙 확보 방법을 확인한다.
- [x] 현금영수증 운영 절차는 대표자/관리자가 입금 확인 후 홈택스에서 수동 발급하는 것으로 정한다. 고객 요청은 `/support`, 전화, 이메일로 접수한다.
- [ ] 사업자등록 업종이 현금영수증 의무발행업종인지 확인하고 홈택스 가맹/발급 권한을 실제 계정에서 점검한다. 의무발행 대상이면 건당 10만원 이상 현금 거래는 요청이 없어도 발급한다.
- [x] PG 결제는 도입하지 않고 고객 결제 수단을 계좌입금으로 확정한다.
- [ ] 개인정보 처리 위탁처를 확정한다: SMS, 이메일, 배송조회, hosting, 이미지 저장소.
- [x] 신고 면제 사업자로 표시하며, 향후 자진 신고 시 공정위 등록현황과 실제 신고번호를 다시 확인한다.
- [ ] 초기 판매 상품별 안전인증, KC, 상품정보제공고시 항목을 확인한다.

## Customer-Facing Pages

- [x] `/company`에 상호, 대표자명, 사업자등록번호, 통신판매업 신고 면제, 사업장 주소, 반품 주소, 호스팅 제공자, 고객센터 연락처가 보인다.
- [x] footer에 사업자 정보와 정책 링크가 보인다.
- [x] `/support`에서 문의 수집 목적, 항목, 보유 기간, 동의 거부권과 동의 증적이 확인된다. B-061에서 처리했다.
- [x] `/policies`와 `/policies/{slug}`에서 이용약관, 개인정보처리방침, 배송 정책, 취소/환불 정책, 결제 후 품절 안내에 접근할 수 있다.
- [x] 정책 페이지 본문에서 개발 단계 안내 문구와 확정되지 않은 혜택/보장 표현을 제거한다. 정책 버전의 `prelaunch-*` 표시는 실제 시행일 확정 전까지 별도 차단 항목으로 유지한다.

## Policy Content

- [ ] 이용약관에 서비스 이용, 주문, 결제, 품절/출고 지연 가능성, 책임 제한, 분쟁 처리 기준을 정리한다.
- [ ] 개인정보처리방침에 수집 항목, 처리 목적, 보유 기간, 제3자 제공, 처리 위탁, 파기, 권리 행사, 보호책임자를 정리한다.
- [x] 배송 정책에 배송비 포함 기준, 배송 그룹, 발주/송장/배송완료 기준을 정리한다.
- [x] 취소/환불 정책에 청약철회 기간, 반품/교환 접수 기간, 배송비 부담 기준, 환불 처리 기준을 정리한다.
- [x] 결제 후 품절 안내에 공급처 품절 가능성과 배송 그룹 주문 단위 환불 기준을 정리한다.
- [x] 계좌입금 안내에 입금 계좌, 입금자명, 입금 기한, 미입금 취소, 입금 불일치 처리, 현금영수증 요청 기준을 정리한다.
- [x] 공개 취소/환불 안내에서 미사용 PG 환불 문구를 제거하고 계좌입금 수동 환불 기준만 남겼다. B-067에서 처리했다.
- [ ] 공개 정책의 `prelaunch-*` 버전과 시행일을 실제 오픈 버전으로 확정한다.

## Product Registration

- [ ] 안전모, 안전화, 안전대, 마스크, 보안경 등 보호구는 인증서, 인증번호, KC 또는 안전인증 대상 여부를 확인한다.
- [ ] 상품명, 제조사/수입자, 원산지, 재질, 규격, 사용상 주의사항, AS 기준을 상품 고시에 입력한다.
- [ ] 상세 이미지에 반품/환불/품절 정책만 묻어두지 않고, 상품 고시와 정책 페이지에도 텍스트로 고지한다.
- [ ] 공급처 상세 이미지 사용 권한과 브랜드/상표 노출 권한을 확인한다.
