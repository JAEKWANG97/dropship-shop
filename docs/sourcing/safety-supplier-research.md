- 관련 항목: B-096
- 확인일: 2026-08-06
- 범위: 공개 정보 조사와 연락 우선순위 결정까지
- 금지 범위: 실제 연락·문의 전송·회원가입·계약·구매·결제·운영 데이터 변경

## 결론

29곳을 확인해 중복 몰과 공급 근거가 약한 7곳을 제외했다. 후보 22곳 중 실제 연락 가치가 있는 적격 업체는 17곳이며, 1차 연락 3곳·2차 연락 14곳·보류 5곳이다. 목표 20곳에는 3곳 부족하지만 공식 B2B·공급 근거가 없는 업체를 억지로 추가하지 않고 PASS 처리한다.

1차 연락은 **코레카 → 크레텍 → 아주세이프티** 순서다. 세 곳 모두 일반 소매점과 달리 도매 또는 B2B 공급 구조가 직접 확인된다. 다만 공개 도매가만으로 도매꾹 대비 우위를 증명할 수 있는 곳은 아직 없으므로, 연락의 목적은 `거래 가능 여부`보다 **실제 공급가·직배송·상품 데이터 사용권** 확인에 있다.

## 현재 Coreable 공급 공백

[공개 상품 API](https://coreable-saf.com/api/products?size=100) 기준 상품은 999개다. 81개 카테고리 중 39개가 0개이고, 17개는 1~9개다.

- 0개인 주요 일반 카테고리: 일반 작업장갑, AED, 세안기, 분진측정기, 진동측정기
- 0개인 주요 스마트 카테고리: 스마트 안전모·조끼·안전대·가스감지기, AI CCTV 다수, 위치·출입·SOS, 중장비 접근경보, IoT 계측기
- 1~9개인 주요 카테고리: 생명줄 3, 산소농도측정기 3, 응급처치용품 4, 냉·온열질환 예방물품 3, 조도측정기 4, 추락방지망 2, 안전블록 8
- 과다 편중: 안전화 79, 보안경 67, 용접장갑 67, 경광등 64, 구급함 63, 바리케이드 57

따라서 범용 PPE만 추가하는 업체보다 일반 작업장갑·AED·가스/산소/분진 계측기·세안대·스마트 안전장비를 채우는 업체를 높게 평가했다. 현재 판매가는 [가격 정책](../policies/pricing-policy.md)의 공급가×1.25를 유지하며 공급처 배송비는 공급가와 판매가에 합산하지 않는다.

### 상위 5곳에 먼저 물을 이유

1. **코레카**: [사업자 전용 B2B](https://koreca.net/goods/catalog?code=00060003)가 도매가·재고를 제공하고, 1켤레 주문·15시 이전 당일출고·10만원 이상 무료배송·VAT 별도를 공개한다. Coreable의 0개 카테고리인 일반 작업장갑을 가장 빠르게 시험할 수 있다.
2. **크레텍**: [산업 유통 구조](https://www.cretec.kr/kor/business/summary.jsp)와 [CTX 연동](https://www.cretec.kr/webzine/sub/wz_view.jsp?bid=1&col=&num=3592&pg=1&sw=&wz=)이 확인된다. 단일 브랜드보다 넓게 도매꾹을 대체할 가능성이 가장 크다.
3. **아주세이프티**: [공식 사이트](https://www.ajusafety.com/)가 전국 도매협력사·광범위 제품군을 명시하고, [직거래 제품](https://blog.daara.co.kr/sell_list.html?cid=ajusafety)은 가격협의 방식이다. 도매가와 중립포장만 맞으면 범용 공급처 후보가 된다.
4. **서브원**: [중소·개인 사업자도 가능한 MRO 도입](https://www.serveone.co.kr/kr/support/new-introduction-guide.do)과 실시간 재고·자동발주가 강하다. 다만 구매대행 고객이 아니라 재판매자에게도 공급하는지 먼저 확인해야 한다.
5. **아이마켓코리아**: [MRO·전문유통·물류](https://www.imarketkorea.com/)를 한 회사에서 제공한다. K2 하이터치2 같은 안전용품도 다루지만, 판매자 계정·최종고객 직배송·상품정보 제공 조건이 핵심 관문이다.

## 공급처 확정 후 필요한 개발

지금은 개발하지 않는다. 거래 조건이 확정된 공급처에 대해서만 별도 backlog로 진행한다.

1. 공급처별 SKU와 Coreable 상품을 연결하는 `supplier_product` 데이터 모델
2. 공급가·재고·MOQ·주문단위·단종 상태 동기화와 변경 이력
3. CSV/API/SFTP 중 실제 제공 방식 하나에 맞춘 최소 importer
4. 공급처별 주문서 생성, 송장 회신, 품절 재처리
5. 이미지·상세 사용권 증빙과 상품정보제공고시·안전인증 원문 보존
6. 공급처 우선순위, 대체 공급처, 배송비를 반영한 운영자 선택 흐름

API나 자동화는 공급처가 파일/API를 실제 제공한다고 확인되기 전에는 만들지 않는다.
